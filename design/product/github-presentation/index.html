GitHub presentation

The README banner, the wordmark and the repository's social preview. This page is their source: npm run docs:brand screenshots the three pieces of artwork below at 2× into docs/assets/readme/, so a token change is one re-run away from a new banner, and no image editor holds a second copy of the brand.

Four rules this artwork follows.

1 · The icon is used as it ships. resources/icon.png, unmodified: no recolour, crop, outline or effect (TRADEMARKS.md).

2 · Every glyph is Cascadia Mono. It is bundled and OFL-licensed, so the images render identically on any machine. The system sans would rasterise as a face whose licence is not ours to redistribute in marketing images.

3 · No third-party name or mark. The terminal strip shows a bare prompt glyph and a cursor – no command name – so the banner and the social preview say "a terminal agent" without naming one. The README says which agents in words.

4 · Flat and square. 1px borders, border-radius: 0, no shadow, no gradient, solid backgrounds (the edge disappears against both GitHub canvases, and a viewer that ignores <picture> still shows a legible light banner).

Banner – dark

Shown by GitHub's dark themes through <picture> with prefers-color-scheme: dark. 800×200 layout, exported at 1600×400.

Banner – light

Shown by GitHub's light theme, and the fallback <img> for any viewer that does not honour <picture>. Same geometry; indigo replaces violet for the accent.

Social preview

The card link sites draw for github.com/qodeca/erfana. 640×320 layout, exported at 1280×640 (GitHub's recommended size); content stays inside the 1200×560 safe area. Dark only – it is not theme-aware. Uploaded by hand in Settings after the README merges.

Frames, pane bars and the selected line are decorative and carry no meaning; the README says in text everything the banner shows.

What it deliberately does not do

Not thisWhy
A screenshot in the bannerThe demo loop below the banner is the real app. A second, static picture of it would compete and go stale.
An SVG bannerAn SVG inside <img> cannot load a web font; outlined text would make the source uneditable.
Transparent backgroundsA viewer that ignores <picture> would show the dark wordmark on a dark page.
A command name in the terminal stripIt would put a third-party name into Erfana's own brand image.
