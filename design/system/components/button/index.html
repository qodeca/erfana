Buttons

Three variants. Hover and click them — the states are the real ones, not screenshots.

The primary button's label is near-black, not white. The brand violet is a light tint, so white on it measures 2.2:1 and fails WCAG 1.4.3. #161312 on the same violet measures 8.4:1. This is guarded by Dialog.contrast.test.ts in the app — if you draw a violet button with a white label in a design, the test will reject the implementation.

focus ring 2px solid violet, offset 2px. Never remove it.

Order and wording

Destructive action on the right, cancel on its left. The label says what will happen — "Delete file", not "OK". A button that cannot be undone never gets keyboard focus by default, so pressing Return twice cannot trigger it.
