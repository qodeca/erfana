Typography

Erfana is a desktop editor, so the type scale is small and dense. The default body size is 13px, not 16px. Sizes below are rendered at their true size — what you see is what the app shows.

Size scale

10px and 11px are label sizes, not text sizes. Use them for a chip, a count or a column header. Anything a reader has to actually read starts at --text-base.

--font-mono
