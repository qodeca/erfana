Motion

Hover a bar to see its duration. Erfana's transitions are already disciplined — in 46 stylesheets, exactly one hardcodes a duration. Animations are the problem.

Durations

The gap. Every duration token bakes ease into its value, so any other curve has to be written by hand and can never be themed. And nothing in the scale is longer than 0.3s, which is why every spinner in the app invented its own length. Two additions are proposed: an easing set (--ease-standard, --ease-out, --ease-linear) and --duration-spin: 0.8s.

One spinner

Erfana currently has — copies of a spin keyframe plus renamed clones of the same thing — running at different speeds. This is the one. It lives in the shared utilities stylesheet and nothing redefines it.

When motion must stop

Anything that repeats forever must stop under prefers-reduced-motion: reduce. Spinning, pulsing, shimmering, flashing. For some people this is not a preference — looping motion causes nausea and dizziness. The setting is how they tell you.

The spinner above obeys it. If your system is set to reduce motion, it is a static ring right now and the app is still perfectly usable — which is the point. stylesheets in Erfana animate with no reduced-motion escape, including a full-screen camera flash and several infinite spinners.

Per-file opt-in is why that number is what it is. Four files do it correctly, and one of those disables the very same spin keyframe another file leaves running. The rule belongs once, in the entry stylesheet, not once per component — a list this long is not carelessness, it is the predictable result of asking every author to remember.
Kind of motionUnder reduce
Infinite spin / pulse / shimmerStop it. Keep the shape so the meaning survives.
Full-screen flash or wipeRemove entirely. Never negotiable.
Slide-in of a new elementCross-fade instead — no travel.
Colour or opacity change on hoverKeep. It does not move, so it is safe.
One thing that must never animate: the height of the HTML preview's permission band. The previewed page sits in a native view that moves in one step, so an eased height would race it and expose page pixels underneath the buttons. Instant height also means there is no reduced-motion case to handle.
