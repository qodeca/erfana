# Renderer

Rules for `src/renderer/` that are not readable from the code. Moved from the root CLAUDE.md so they load only for renderer work. Index: docs/README.md

- Panel ids and panel opening: never hand-build an `editor-…` / `image-…` / `preview-…` id. An id past `PANEL_ID_PATH_BUDGET` (180 sanitized chars) is shortened to a 150-char head plus a 16-hex digest, so never read a path back out of an id. Use `getFilePanelId()` / `openFileInPanel()` from `src/renderer/src/utils/openFileInPanel.ts`, so the id prefix, `component` and `tabComponent` are all derived from one `isImageFile` call and cannot disagree. An ESLint `no-restricted-syntax` selector (in the same `src/renderer/**` block as the Windows-path rules) catches it (#70) for the `editor-`, `image-` and `preview-` prefixes – but only the `` `editor-${sanitizeFilePath(…)}` `` shape: the `sanitizeFilePath` callee is part of the selector on purpose (a bare `` `editor-${x}` `` is also a legitimate React key), so any other expression passes lint and has to be caught by review
- Renderer platform detection: use `isMacOS()` / `isWindows()` from `src/renderer/src/utils/platform.ts` (backed by the sync `window.api.utils.getPlatform()` bridge). Never read `navigator.platform` or `process.platform` in the renderer — `process.platform` is `undefined` under the sandbox
- Renderer path handling: derive basenames, dirnames, and display relative paths via the cross-platform helpers in `src/renderer/src/utils/fileUtils.ts` (`getBasename`, `getDirname`, `stablePathDigest`, `getDisplayRelativePath`, `isPathInside`, `isStrictDescendant`) — never `filePath.split('/')`, `lastIndexOf('/')`, or POSIX-only path math, because the main process passes **native** separators across IPC (paths can contain `\` on Windows). The ESLint `no-restricted-syntax` rule over `src/renderer/**` catches only **two path shapes** – `.split('/').pop()` and `x.endsWith('/') ? x : x + '/'` – and exempts three files - `utils/fileUtils.ts`, `utils/openFileInPanel.ts` and `services/preview/OverlayGuardService.ts` (the third for a preview-visibility selector, not a path one). Every other POSIX-only form (`lastIndexOf('/')`, a bare `.split('/')`, manual joins) is convention only and passes lint, so review for it by hand. These helpers are display/parse-only — they are **not** for filesystem confinement; real confinement stays main-side in `ExternalFileService` via `realpath`
- Autosave must never lose keystrokes: a save in flight, its own echo event, and local edits made during the save are each guarded separately in `useFileWatcher`, and `MarkdownEditorPanel` re-checks the Monaco buffer after every write. While the unsaved-changes prompt is open, autosave is held (`editorSaveRegistry.holdAutosave`, counted per panel, released when the last hold ends), so a "Don't save" answer is never pre-empted by a write. See [docs/file-watching/README.md](../../docs/file-watching/README.md)
- Panel-scoped globals need an active-panel gate: dockview keeps **every** opened panel mounted, so a `window` listener registered inside one runs once per open tab. `useKeyboardShortcuts` therefore takes an `enabled` flag and `MarkdownEditorPanel` wires it to `props.api.isActive` (kept in step via `onDidActiveChange`) — without it one ⌘W closed every tab and one ⌘S wrote every open buffer to disk. Any new panel-level shortcut, `document` handler or "current file" singleton needs the same gate. See [docs/keyboard-shortcuts.md](../../docs/keyboard-shortcuts.md)
- Error containment (two tiers): a new panel wraps its content in `<PanelErrorBoundary componentName="…">` **keyed by whatever scopes that content** (e.g. `key={projectPath ?? 'none'}`, see `src/renderer/src/components/Panels/ProjectPanel.tsx`), so a defect degrades that panel instead of the window – without the key a panel that failed on project A still reads "unavailable" after switching to project B. `RootErrorBoundary`, `installGlobalErrorTrail()` and the main-process crash handlers are the outer layers: [docs/ui-components.md § Error containment](../../docs/ui-components.md#error-containment)
