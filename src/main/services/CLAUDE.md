# Main-process services

What the non-obvious services under `src/main/services/` are for. The directory
listing itself is derivable (`ls`, plus
[architecture.md](../../../docs/architecture.md)) — this catalogue is not: every
entry below carries a reason or the issue that drove it, and a service with
neither is deliberately absent.

**Core** – `file/`: imageRead [#70: version-gated image read – stat-before-read, so an unchanged asset costs no base64 encode and no multi-MB IPC payload].

**Watchers** – `watcher/`: SubscriberCounter [#70: per-webContents subscription counting so two panels in one window cannot cancel each other's watch], singleFileWatch [#70: the one place a single-file chokidar watcher is built, incl. the load-bearing `disableGlobbing: true` v3 pin], atomicRearm [#70: the unlink branch – atomic save re-arm vs genuine delete, incl. the realpath confinement re-check], rearmingSingleFileWatch [#74: reusable self-re-arming single-file watcher composing singleFileWatch + atomicRearm, used by the HTML-preview entry watcher and subresource pool so a preview keeps live-reloading across atomic editor saves], watchNotifier [#70: the BrowserWindow send loop behind every watcher notification].

**Media / export** – ScreenshotService (dispatcher → `screenshot/`: sharedHelpers [#164]), HtmlToDocxConverter (strips remote images + wraps, then delegates conversion to a killable utilityProcess child), `docx/`: docxImageStrip [parse5 remote-image SSRF strip before export], DocxConvertProcessAdapter [utilityProcess lifecycle + kill-on-timeout], docx-convert.process [the isolated child entry]; `imageExport/`: ImageExportService orchestrator [#73: PNG / PDF / clipboard export from the image viewer — reads the file fresh from disk on every run, so the output follows the file and never the panel], imageMetadata + declaredDimensions [#73: bounded, never-throwing header parsers over untrusted bytes — GIF frame count, ICO directory, SVG intrinsic size, and the declared-dimension preflight that refuses a decompression bomb before any byte reaches a decoder], exportPaths [#73: suggested filename, forced extension, and the fail-closed self-overwrite guard], pdfGeometry [#73: the one-page / MediaBox gate that runs before the PDF is written, sharing its tolerance constant with the e2e assertion], rasterizeSession + ImageRasterizeWindow [#73: the hidden hardened decoder window — own in-memory partition, deny-all `webRequest` allow-list installed before the window exists, per-run UUID token and sender-frame check, guaranteed destroy, every wait time-boxed by the shared `withTimeout` (`src/main/utils/withTimeout.ts`, no longer private to this window — the preview session, allowlist, still-frame and live-view paths use it too)], exportSinks [#73: the three sinks — save-dialog write, `printToPDF`, `clipboard.writeImage`]; whisper-assets (pinned release + classifyPlatform), whisper-pubkeys (dual minisign keys).

**Claude status** – `claudeStatus/`: ClaudeStatusService orchestrator, ClaudeTranscriptWatcher [refcounted chokidar on ~/.claude/projects], fallbackGuard [#47: per-file-version bounded-read result cache, caps the post-compaction transcript re-read], ClaudeWindowDetector [window-sizing rule chain 200k/1M], modelId [#41: shared model-id parser + exact-id capability registry, the single window-policy entry point], encodeCwd [platform-branched: macOS `/`+`.`→`-`, Windows `/`+`\`+`:`+`.`→`-`], `process/`: WinClaudeProcessDetector [#217], exec (shared ExecLike).

**HTML preview (#74, extended by sd-074b)** – `preview/`: PreviewViewService [WebContentsView lifecycle owner — mints/moves/destroys the native overlay views], PreviewViewRegistry [the live-view map keyed by panelId with its owning window, the split generation/openSeq race guard, and the least-recently-active ordering that drives sleep-when-idle], PreviewNavigationPolicy [pure decision table for a clicked link] + previewLinkNavigation [the side effects that follow: confinement, renderer hand-off, OS hand-off, failure entry] + previewLinkBridge [payload validation, rate limit, and de-duplication of the preload and will-navigate paths], previewWatchBudget [process-wide watch ceiling shared by every per-view pool], PreviewLiveView [the live page wrapper it drives], PreviewProtocolHandler + PreviewRequestFilter [`erfana-preview://` serving + per-request/host gating and CSP enforcement], PreviewAllowlistStore [one-way per-project ORIGIN allowlist — scheme, host and port — cap 200, kept out of ProjectSettings by design so a malformed entry can't block project load; the read and write paths resolve through the same schema ladder], PreviewSessionFactory [mints the sealed in-memory `session`, and RECYCLES purged partition names — Electron cannot destroy a session, so every fresh name costs handles for the life of the process; it also drains the allowlist store's load-time badges onto the new view, so a malformed allowlist block reaches the tab that opened it rather than only the process-wide log (#115)] + PreviewStorageSeal [the purge: seven named storages (`PURGED_STORAGES`, which deliberately omits `shadercache` — it never settles on Windows and holds compiled GPU programs, not page data) plus the HTTP, auth, host-resolver and code caches, then closes every warm connection], previewSessionPolicy [the single construction site for the view's `WebPreferences` and the runtime session hardening — deny every permission, block downloads, narrow WebRTC local-IP exposure — plus the partition naming; it never touches response headers, so the CSP keeps one owner], previewViewLifecycle [attaches every navigation guard and lifecycle listener a view needs and returns one async disposer], previewBackdrop [pure state machine for the colour behind the page: brand black until the page paints, then the page's own resolved paper colour], PreviewEligibilityService [decides whether a path may open as a running preview], PreviewRootRegistry [tracks the served project roots], PreviewWatchCoordinator + PreviewWatchPool [bounded autorefresh watch pool], PreviewExportController [PDF export], PreviewFindController [find-in-page], PreviewFailureLog + PreviewStillFrameCache [coalesced failure log; a still-frame capture is STARTED only while the view is drawn, but its retry after an empty first capture may land after the tab was switched away — the caller's `shouldKeep` veto guards a REPLACEMENT, and an empty slot is exempt, because on macOS the first capture is always empty and honouring the veto there parked the tab on a bare backdrop for good], PreviewReloadPolicy [reload gating]. IPC handlers live in `src/main/ipc/preview/` (allowlist-handlers, find-handlers, lifecycle-handlers, externalLinkConsent [the parented, per-window-gated consent question between a previewed page and the OS browser], isTrustedPreviewSender, emit, buildPreviewGraph).
