## 0. Ground rules

The Wave 1 rules still hold: `npm ci` only, branches off `develop`, PRs through the merge queue, Conventional Commits, the local gate before every push, e2e for Electron-facing changes.

- **Wording:** Wave 2 hardens the file and terminal IPC. Keep commit messages, PR text and issue comments neutral: say "harden" or "check", not "exploit" or "bypass". Do not describe how to misuse v0.20.1 anywhere public.
- Log lines must not hold full paths (#265). Use `redactQuotedPaths` / `loggableError` when you add one.
- Wave 2 changes `FileService` and the file IPC, which #265 also touched. Rebase on `develop` before you start a fix.

## 1. What Wave 2 changes

| PR | What | Windows risk |
|---|---|---|
| PR-1 `feature/project-session` | The main process owns one project session (root + a generation number). Open, switch and close run one at a time. `file:getLastProjectPath` is removed | Low |
| PR-2 `feature/flush-before-switch` | Unsaved editor tabs are saved before a project switch or close. A tab that cannot be saved makes the app ask first | Medium – a save that hits a locked file during a switch |
| PR-3 `feature/shared-file-types` | `FileNode` / `FileStats` move to `src/shared/ipc/file-schema.ts`; ESLint layer rules | None |
| PR-4 `fix/file-ipc-confinement` | Every `file:*` channel checks each path argument in main: the path must resolve (through `realpath`) inside the open project. Paths in `\\?\`, `\\.\`, `\??\` form, drive-relative paths (`C:foo`), alternate data streams (`x.md:s`) and segments that end in `.` or a space are refused. New names are checked for reserved names (`CON`, `NUL`, …). Handlers return the path in the form the renderer sent it (`Z:\`, short names), and act on the resolved one | **High** – everything in § 3 |
| PR-5 `fix/external-file-target` | Import from outside the project resolves its target against the session, not a renderer argument | Medium |
| PR-6 `feature/terminal-contract` | `terminal:*` gets schemas; the renderer can no longer pick `shell` or `env`; the start folder goes through the same path check | Medium – start folder on a UNC share or `subst` drive |
| PR-7 – PR-9 | Typed bridges (`FileBridge`, `TerminalBridge`), object payloads, renderer gateways | Low |

Also in Wave 2 (owner decisions, 2026-10-21):
- A project opens only from a dialog pick or the recent list. e2e opens test folders through a test-only main hook.
- A single save is limited to 64 Mi characters.
- Writing through an in-project link (symlink or junction) that points outside the project is refused. Reads already were.
- `file-watch:*` / `directory-watch:*` paths go through the same check.

## 3. Path facts, before PR-4 (do this first)

The path check calls `fs.promises.realpath` on both the project root and the requested path, then compares them. It is only as correct as what `realpath` returns on Windows, and that has not been checked on this branch. Record what Node returns, both from plain `node` and from Electron's own Node (put the calls in `probe.js`, then run `$env:ELECTRON_RUN_AS_NODE=1; node_modules\electron\dist\electron.exe probe.js`).

Set up, in a scratch folder under `%TEMP%`:

```powershell
mkdir C:\erf-probe\Proj\sub; "a`r`nb`r`n" | Set-Content -NoNewline C:\erf-probe\Proj\crlf.md
subst Z: C:\erf-probe                                    # undo later: subst Z: /d
New-Item -ItemType Junction -Path C:\erf-probe\Proj\jn -Target $env:TEMP
New-Item -ItemType SymbolicLink -Path C:\erf-probe\Proj\sl -Target $env:TEMP   # needs Developer Mode
cmd /c "dir /x C:\Users"                                 # find your 8.3 short name, e.g. NAME~1
```

For each input below, record `path.resolve(x)`, `await fs.promises.realpath(x)`, `fs.realpathSync.native(x)`, and `fs.lstatSync(x).isSymbolicLink()` (or the error code):

| # | Input |
|---|---|
| F1 | `C:\erf-probe\Proj\sub` and `c:\ERF-PROBE\proj\SUB` (case) |
| F2 | `C:/erf-probe/Proj/sub` (forward slashes) |
| F3 | `Z:\Proj\sub` (`subst`) |
| F4 | `C:\Users\NAME~1\AppData` (8.3 short name) – and a path under it that does not exist yet |
| F5 | `\\localhost\C$\erf-probe\Proj\sub` (UNC) |
| F6 | `\\?\C:\erf-probe\Proj\sub` and `\\?\UNC\localhost\C$\erf-probe\Proj` |
| F7 | `C:\erf-probe\Proj\jn` and `C:\erf-probe\Proj\jn\x` (junction pointing outside) |
| F8 | `C:\erf-probe\Proj\sl` (symlink pointing outside), if you could create it |
| F9 | `C:\erf-probe\Proj\sub.` and `C:\erf-probe\Proj\sub ` (trailing dot and space) |
| F10 | `C:\erf-probe\Proj\crlf.md:zone` (alternate data stream) |
| F11 | a mapped network drive, if one exists (`net use`) |

Also record: does `realpath` ever return a `\\?\` prefix? Does it fold case? Does it expand 8.3 names? Does it resolve `subst` to `C:\`?

Put the table in the report (§ 6) **and** send it to the macOS session as soon as you have it – PR-4's Windows unit rows are written from it.

## 4. Checks per PR (run each when the PR is on `develop`)

Each PR comes with unit tests that run on every host. The checks below are what only a real Windows disk shows. Run the built app (`npx electron-vite build`, then `npx playwright test` or the app itself). Record the command and the output.

**After PR-2**
- **W1**: open project A, type in `a.md`, and switch to project B within half a second. `a.md` on disk must hold the edit.
- **W2**: hold `a.md` open with the S1 command from Wave 1 (`FileShare 'Read'`, so every writer is refused). Type and switch. The app must say one tab could not be saved. Cancel keeps A open; the edit is still in the tab.

**After PR-4** (the largest one)
- **C1**: run the new unit tests on this host: `npx vitest run src/main/ipc/confinement`. The `win32` real-disk block runs only here and in the advisory `Windows checks` job. All must pass.
- **C2, drive and case**: open `C:\erf-probe\Proj` from the dialog. Create, rename, move, copy and delete files in the tree. Then open the same folder typed with other case through the recent list. Everything must work, and the tree must not show duplicate entries.
- **C3, `subst`**: open `Z:\Proj`. Create, save, rename and delete a file. The tree and tabs must keep showing `Z:\` paths (not `C:\`). Saves must land in `C:\erf-probe\Proj`.
- **C4, 8.3 short name**: open the project through a short-name path (for example `C:\Users\NAME~1\Documents\proj`, typed in the dialog's address bar). Create a nested folder and file that do not exist yet, save, rename. All must work.
- **C5, UNC**: open `\\localhost\C$\erf-probe\Proj`. Create, save, rename, delete. All must work. Then try, from DevTools (`Ctrl+Shift+I`) with the project open, `await window.api.file.readFile('\\\\localhost\\C$\\Windows\\win.ini')`. It must be refused with the "outside the project" message.
- **C6, junction**: with `jn` inside the project pointing at `%TEMP%`: reading or writing `jn\x.md` must be refused. Deleting or renaming `jn` itself from the tree must work and must leave `%TEMP%` untouched.
- **C7, odd forms**: from DevTools, each of these must be refused, and nothing may be created on disk: `writeFile('\\\\?\\C:\\erf-probe\\Proj\\x.md', 'x')`, `writeFile('C:\\erf-probe\\Proj\\x.md:s', 'x')`, `writeFile('C:\\erf-probe\\Proj\\x.', 'x')`, `createFile('C:\\erf-probe\\Proj', 'CON')`, `createFile('C:\\erf-probe\\Proj', 'aux.md')`.
- **C8, CRLF**: open `crlf.md`, change one line, save. The file must keep CRLF on every line (`Format-Hex crlf.md` shows `0D 0A`). Then rename it and move it into `sub`; the bytes must not change.
- **C9, long paths**: create a nested folder chain inside the project until the full path passes 260 characters. Create and save a file at the bottom. It must work (Node adds `\\?\` itself).
- **C10, speed**: open a large project on the UNC share (or the #208 project). Note in `main.log` the `durationMs` of tree reads and image reads before and after PR-4. Report anything more than 2× slower.

**After PR-5**
- **E1**: drag a file from Explorer into the tree, and import one through the import dialog. Both must land in the project. Move-import must delete only that source file.

**After PR-6**
- **T1**: open a terminal in a project on `Z:\` and one on the UNC share. Each terminal must start in the project folder (`cd` / `pwd` shows it). PowerShell, cmd and Git Bash.
- **T2**: from DevTools, `window.api.terminal.create({ cwd: 'C:\\Windows', cols: 80, rows: 24 })` must return `{ error }`, and no shell may start.

**After PR-9**
- **A1**: the full gate and the full e2e run on this host, with the pass / fail / skip counts.
