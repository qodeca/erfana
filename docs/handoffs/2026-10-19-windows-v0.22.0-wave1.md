## 2. What Wave 1 changed

All eight branches were reviewed by a security reviewer and a code reviewer, and every finding was fixed. On macOS (2026-10-19): the full gate passed, unit tests 8,005 + 198 + 6,781 passed, and e2e 298 / 298 passed.

| Branch (merged) | What | Windows risk |
|---|---|---|
| `fix/status-spawn-isolation` | Git runs from `%TEMP%` with `-C <project>` and an allow-listed env (incl. `PATHEXT`, `XDG_CONFIG_HOME`). It uses `-c` overrides for every config key that can start a program, sets `GIT_NO_LAZY_FETCH=1` and `GIT_ALLOW_PROTOCOL=none`, and runs with `windowsHide`. The null device `\\.\nul` is used for hooks and includes, and the finder is `%SystemRoot%\System32\where.exe`. System `core.autocrlf` / `core.eol` / `core.safecrlf` are read once and passed back. A repo with filter drivers or a promisor remote falls back to the built-in reader. The preview's gitignore check now works, and skips the rule when the project folder itself is ignored | **High** – nothing has run on real Git for Windows yet |
| `fix/atomic-text-write` | Saves write `.erfana-tmp-<uuid>`, fsync it, then rename it over the target. On EPERM / EBUSY / EACCES after retries the save falls back to an in-place write. Read-only files still refuse to save. Symlinks and hard links are written in place. Old temp files are swept at project open, and the tree and the watcher hide them | **High** – rename over a file another app has open |
| `fix/session-permissions-preload` | The default session allows camera video only. The preload exposes only `shell.openExternal` on `window.electron` (`@electron-toolkit/preload` removed). The API key uses `encryptStringAsync`, with a sync fallback and an atomic write. The lock HMAC secret is random, in `%USERPROFILE%\.erfana\lock-hmac-secret.enc`, published with link-if-absent | **High** – DPAPI, upgrade of a key stored by v0.20.1, two instances |
| `fix/external-link-routing` | One check for every outside link. UNC paths, `file:` and `ftp:` are refused; `mailto:` keeps only to/cc/bcc/subject/body. The default window-open is a plain deny | Medium |
| `fix/pdf-export-window` | The PDF export window has its own session, a CSP, `https:`/`data:` images only, and time limits on load, probe and print | Medium |
| `fix/startup-and-logging` | Start-up survives init errors and shows a non-blocking message. `crash.log` is redacted, rate-limited and capped at 1 MB. Log entries are shortened, not dropped. Control characters are escaped. 5 rotated files (was 100). Unhandled rejections are logged, then re-raised as before | Low |
| `fix/confirm-dialog-focus` | Enter follows the focused button; delete / discard / quit prompts open on Cancel | Low |
| `chore/hooks-lint-and-e2e-home` | react-hooks lint. Each e2e worker gets a sandbox `HOME` / `USERPROFILE` / `APPDATA` / `LOCALAPPDATA` with seeded empty shell rc files, and an env allowlist. Temp folders are removed with retries (#134) | Medium – teardown on Windows |

## 4. Windows-only checks

Run each check. Record the command and the output.

**Git**
- **G1**: inside any repo, run `git -c include.path=\\.\nul config --get core.bare`. The exit code must be 0 or 1, **not** 128. If it is 128, every native status falls back to the slow reader, and the HTML preview's gitignore check fails open. Fix it in `src/main/utils/hardenedGit.ts` (`GIT_INCLUDE_OVERRIDE`). Try `include.path=NUL`, then an empty file under `%TEMP%`.
- **G2**: open a large real repo in the built app. Git badges must appear, and `%USERPROFILE%\.erfana\logs\main.log` must not say native git fell back. No console window may flash up during refreshes.
- **G3**: use a repo with `core.autocrlf=true` set **only** in the system config (the Git for Windows default). Open a CRLF file, save it unchanged, and wait for a refresh. The file must **not** show as modified.
- **G4**: in the built app, `where.exe` must find git with the reduced env. If the badges in G2 work, this passes.

**Saves**
- **S1**: hold a file open without delete sharing:
  ```powershell
  $f = [System.IO.File]::Open("$PWD\locked.md", 'Open', 'Read', 'ReadWrite')
  ```
  `ReadWrite` sharing lets a writer in but forbids delete and rename, which is the case under test. (The first version of this brief used `'Read'`, which forbids every writer: the save then fails with the "Save failed" toast and keeps the edit, which is also correct – see the [report](2026-10-19-windows-v0.22.0-wave1-report.md) § 3.)
  Edit and save `locked.md` in Erfana. The save must succeed, and `main.log` must show one fallback warning **with no file path in it**. Then run `$f.Close()`.
- **S2**: with autosave on, save one file 20 times quickly. No `.erfana-tmp-*` may stay in the folder or show in the tree.
- **S3**: run `attrib +r file.md`, then try to save it. It must show the "Save failed" toast and must not overwrite the file.

**Keys and locks**
- **K1, upgrade**: install **v0.20.1**, store an OpenAI key in Settings, and quit. Start a `develop` build against the same `%USERPROFILE%\.erfana`. The key must still be there (Settings shows it as stored). This proves DPAPI data from the old sync API reads with the new async path, which was proven only on macOS.
- **K2**: open the same project in two instances. The second instance must see the first one's lock.
- **K3**: start two instances at the same moment. `lock-hmac-secret.enc` must exist once, and both instances must see each other's locks.

**Links and PDF**
- **L1**: in a Markdown file, click and middle-click links to `\\localhost\c$`, `file://localhost/c:/windows`, `ftp://example.com` and `https://example.com`. Only the https link may open (in the browser). The others must do nothing.
- **P1**: export a Markdown file with a Mermaid diagram and an `https://` image to PDF. Both must appear in the PDF. (No e2e covers Markdown PDF export.)

**Start-up**
- **U1**: make `%USERPROFILE%\.erfana\settings.json` unreadable (`icacls settings.json /deny "%USERNAME%":R`), start the app, then undo it with `icacls settings.json /remove:d "%USERNAME%"`. The app must open with a "started with problems" message, without hanging. The first settings change must leave a `settings.json.bak-<timestamp>` copy.
