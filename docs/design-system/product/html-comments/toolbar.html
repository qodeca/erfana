Comment tools in the toolbar

Three tools join the preview band after Find, because they act on this page: Comment mode, the Comments list and Show comment icons.

Built from the decided Permission band card. Same 32 × 28 tools, same inset ring, same aria-disabled rule (the dim goes on the icon, never the button), and the link toggle's pressed signature – a fill plus a 2px lime edge along the bottom – for every “on”: Comment mode pressed, the drawer open, icons shown. A shape appears, so a state is never colour alone (SC 1.4.1). The icons are the registry's lucide message-square-plus, messages-square and message-square / message-square-off (plan §3). Proposed: the plan files these cards as proposed (§10.11), and the narrow tiers below need re-measuring in nav.css before P6 ships.

The row

Try it. Click Comment mode, or put focus anywhere on this card and press Ctrl+Alt+M (Cmd+Option+M on macOS) – matched on the typed key m, never the physical key, because AltGr+M types µ on a German layout. The page gets its frame and tab, and the band's live region speaks. The accessible name of the toggle never changes; its state is aria-pressed. Esc with focus in the page leaves the mode – it is the second step of the existing Escape order: an open window first, then comment mode, then “return to chip”.

Every state

Unavailable

When a page cannot take comments, Comment mode is aria-disabled – it keeps focus and its tooltip, and the tooltip says why. The list and the pins tool stay usable when the file's comments can still be read (a link, a conflicted file – read-only, but readable); they take the same state when nothing can be read. Narrow panels: re-measured with the new tools

The band never wraps and never changes height; it steps down by container query (decided Permission band card). Three more tools make every tier wider, so the thresholds in nav.css – read below by probing the shipping stylesheet, not typed – no longer match what each row needs. At the minimal tier Show comment icons leaves the row; it stays reachable from the drawer's checkbox. Comment mode and the list stay: Comment mode has a shortcut but is the feature's front door, and the list is the keyboard route to every thread.
