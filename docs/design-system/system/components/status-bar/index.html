Status bar

proposed not yet reviewed

A panel that reports a live value gets one footer strip, .erf-status-bar: --header-height tall, on --color-bg-tertiary with a --border-width top rule. Three slots – the leading identity, a spacer, the trailing values. As the panel narrows the meter goes first, then the badge, then the name ellipsises; the value is never dropped. It is display-only and never a tab stop. One polite live region announces a change of band, and nothing else.

Why a card: two strips, one height, nothing else shared. The Claude Code bar under a terminal and the git bar under the project tree both read --header-height, and their CSS says they should match. They differ in surface (--color-bg-secondary against --color-bg-tertiary), in the top rule (a typed 1px against --border-width), and in text colour – and the git bar's --color-text-secondary on its surface is under 4.5:1. Text follows the Typography card's Status line role (--text-sm, normal, snug, --color-text-tertiary); the name and the values step up to --color-text-primary. A count or window size is the Badge card's .erf-counter.

Every state

Drawn at the app's scale, under the panel each bar closes off. Percentages are examples, one per band.

Collapse order

The same bar as the panel narrows. Each step is a container query on the bar, so it follows the panel, not the window.

Drag the corner

Both bars in a frame you can resize by its bottom-right corner.

The keyboard contract

There is nothing to operate, so there is no tab stop and no tooltip that only the pointer can open. Everything the bar shows is on screen as text, or in the meter's value text.

Open defects this card names

  • Git bar text under 4.5:1. .git-status-bar sets --color-text-secondary on --color-bg-tertiary (the ratio is in the adoption table above).
  • Retired tokens in the Claude Code bar. Its amber and red bands read --color-warning-bright and --color-error-bright, both retired (the Colours card).
  • A typed rule. .terminal-claude-statusbar draws its top rule as 1px solid, not --border-width.
  • Information only in title. The exact token counts and the git bar's partial-count warning live in title, which the keyboard never shows.
  • A band change is silent. Neither bar has a live region; crossing into the danger band is seen, not heard.
  • No collapse order. Neither bar decides what goes first when its panel narrows; the git bar's branch name pushes the counts.

The band thresholds live in src/main/services/claudeStatus/thresholds.ts; this card does not quote them, because a number typed here would drift from the code.

Exceptions

None recorded. A shipping status bar that departs from this card carries a deviates: marker at the site and gets a row here, naming the file.
