Badges, chips and keys

proposed not yet reviewed

Every small label, one rule: the text is the information – a number, a letter, a word, a key name – and colour only repeats it. Whatever a badge says on screen is also said in words to a screen reader, in the name of the thing it is attached to. Nothing here is colour alone, and nothing here hides in a title.

The keyboard contract

KeyResultFocus ends on
TabReaches an action chip; skips static chips, badges, counters and keys.The action chip.
Enter / Space on an action chipOpens or closes what it controls; aria-expanded and the caret flip.The chip, or the first item it opened when it opened by keyboard.
Esc in what the chip openedCloses it.The chip.

The activity-bar item that carries a badge is its own control, with its own contract; the badge adds nothing to focus. The Permission band's chip is held to this by PreviewChromeBand.test.tsx. No test covers the badge, git or key styles yet.

Counter3“Comments, 3”Plain text beside its label, read as one name.
Attention counter▲ 2“Blocked hosts, 2 failed”The words go in the parent's name; the counter is aria-hidden and the triangle has empty alternative text.
Dot, unseenA square“Comments, new since you last looked”The item's name; the dot is aria-hidden.
Chip, outline or accentChanged, New“plan.md, changed”The word is visible text; the tone adds nothing a listener needs.
Key⌘F“Command F” where the caption is read; the control says it via aria-keyshortcuts="Meta+F"Visible text and the attribute, never title alone.

The markup

<!-- Badge: the name carries the number -->
<button class="activity-bar-item" aria-label="Project, 128 changed files">…<span class="erf-badge" aria-hidden="true">99+</span></button>

<!-- Git, file row -->
<div role="treeitem" aria-label="plan.md, modified">plan.md <span class="erf-git" data-git="modified" aria-hidden="true">M</span></div>

<!-- A shortcut shown, and declared: one box, the text formatShortcut('F', { mod: true }) returns -->
<button aria-label="Find" aria-keyshortcuts="Meta+F">…</button>
<kbd class="erf-kbd">⌘F</kbd>

Open defects this card names

  • The folder git dot is colour alone (#95) – .git-status-dot; renamed measures under 3:1 (the table above).
  • The git counts read as letters – GitStatusBar.tsx renders “M3”, read aloud as “M3”; renamed has no count.
  • The activity-bar badge keeps its value in title – ActivityBarBadge.tsx; both sources return null today, so nothing renders yet.
  • No attention count and no tones ship yet – the attention counter and the chip tones are proposals; no app class draws them.

Related

  • Colours – owns every token named here.
  • Feedback – the severity words a banner or toast uses; the attention counter is the inline count, not a banner.
  • Writing – Keyboard shortcuts – owns how a shortcut is spelled.
  • Permission band – the action chip's reference.

Exceptions

None recorded. A shipping component that departs from this card carries a deviates: marker at the site and gets a row here, naming the file.
