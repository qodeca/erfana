Origin field

proposed not yet reviewed

A field that says where you are is .erf-origin in origin-field.css: a Form-card field at --input-height-sm whose text is the origin display – the registrable domain brightest (--color-text-emphasis), subdomain labels, scheme, port and path quiet in tertiary – with a state badge fused to its start and action chips at its end. When it does not fit, the path loses its end first, then whole subdomain labels leave from the front; tools leave the row before the registrable domain could be cut, and only as the last resort it loses its start, never its end. It never shows a page title or any text the page supplied.

Why a card, when Rows and lists already decides hosts. The Rows card answers a host that does not fit with “wrap, never cut” – right for a list row, impossible in a one-line field. The Form card decides fields, not what an address looks like. The browser (spec 025) needs both at once: a field that must stay one line and an origin that must stay honest. This card takes every origin rule the Rows card decided – scheme only when not https, port only when not default, both dimmed; punycode for a label that mixes scripts; the full origin in real text for assistive technology – and adds the three a one-line field needs: emphasis, elision order, and what may never sit in it.

__badge
The state in a word plus an icon: “Not secure” (circle-alert in --color-warning on http to a remote host – round, never a lock, so the icon-only form cannot read as “safe” and differs in shape from the triangle; error triangle after a certificate failure), “File”. None for https or a loopback or private http address. The segment has a hover tooltip with the deck description, so the icon-only form can be read back. Never shrinks; the word stays until every optional tool has left the row, then .erf-origin--badge-icon keeps only the icon (exception below).
__scheme
Drawn only when not https, tertiary.
__sub
Subdomain labels, tertiary, so the domain is the one bright run. The first thing to leave after the path – whole labels, from the front, replaced by __elide.
__elide
“….” – the ellipsis and the dot that separated the dropped labels, tertiary, so the cut never reads as part of the domain.
__domain
The registrable domain, emphasis. Never shrinks while anything else can give way; as the last resort (exception below) the formatter slices off its start and writes a leading “…”, keeping its end, TLD and port – never its end. The component knows where it starts from the public-suffix list (browser note OD-1); CSS cannot.
__port
Drawn only when not the scheme’s default, tertiary.
__path
Path, query and fragment, tertiary. The only part CSS cuts, from its end, with a floor of 2 characters: below that the component drops it whole – never a one-letter sliver.
__chips
Action chips (Badges card): zoom, pop-up blocked, in use. Zoom leaves the field before the badge or the domain do; the in-use chip never leaves – it pins to its icon. A focused chip has the one ring, inset; the field draws its own ring only while the text has focus.
__input
The real <input> while typing (frames draw it as __typed spans to show a caret and a selection).

Every state

The suggestion list

Which address it shows while loading

The pending address only for a load the user started (typed, Reload, Back or Forward, a history row, a terminal link). For a load the page started (script, link click, form, redirect) the committed address stays until the new page commits – otherwise a page could show an address it never reaches (browser Security rule 1). The editor tab’s label and description follow the same rule: for a page-started load they keep the committed page’s title, or its host, until commit. No class: the component chooses which URL to hand the display. Both cases are drawn above.

User names in a URL, and links that are not web addresses

A user name and password written into a URL (https://accounts.harbour-garden.org@evil.example/ – everything before the @) are stripped on every display: the field at rest, the editor tab and its tooltip, the link destination, the link menu’s header, history rows. Only the focused, editable field shows them, unemphasised. A link that is not http, https or file shows the scheme word and a plain description (.erf-origin__other), never a host in bright text.

What never goes in the field

A page title, or any text the page supplied. The display is filled from the engine’s committed URL only. A title appears in the editor tab and its tooltip (Tabs card), where the tooltip leads with the true address. No lock, no tick and no badge ever sits beside a title. A colour for “safe”. https gets no badge rather than a green one: the absence of a warning is the normal case, and a reassuring colour is the thing a page would imitate.
