Tabs

proposed not yet reviewed

One tab, .erf-tab, for every document a panel group shows. The selected tab has a lime underline in every group; the focused group sits on the panel surface. Unsaved and deleted are said in a shape and in words, never in colour alone. Close is a 24 × 24 target, and the keyboard closes a tab with Delete.

Why a card: three copies already drift. EditorTab.css, HtmlPreviewTab.css and ImageTab.css each carry the same tab under its own class name. EditorTab.css and ImageTab.css type height: 41px (2 of the three files) where HtmlPreviewTab.css reads --tab-height (41px); the same two give the close button border-radius: 0 (2 files) where HtmlPreviewTab.css reads the token; the 80px floor and 300px ceiling are typed in 3 of the three, and again as !important dockview overrides. tabs.css is the one file they become.

The underline and the stacking order

Today the active underline is an ::after with z-index: 100 in AppDockLayout.css – the exact value of --z-dropdown, so where the underline and a dropdown overlap, DOM order decides the winner (the Layering card records it). This card removes the number instead of choosing a rung: a positioned ::after already paints above the tab's own content, and .erf-tablist sets isolation: isolate, so nothing inside the strip takes part in the global stacking order.

The keyboard contract

The strip is role="tablist"; each tab is role="tab" with aria-selected and aria-controls its panel; dockview owns those attributes today. One tab stop for the whole strip (roving tabindex). Activation is automatic – the panels are already mounted, so moving is cheap.

Open defects this card names

  • The tab strip has no arrow-key, Home/End or Delete handling and no test for any of it.
  • The close button is shown only on hover or when dirty – never for keyboard focus and never on the selected tab.
  • The active underline's z-index: 100 ties with --z-dropdown (AppDockLayout.css).
  • Three copies of one tab with drift between them, listed above.

Exceptions

None recorded. A shipping tab that departs from this card carries a deviates: marker at the site and gets a row here, naming the file.
