Brand

proposed not yet reviewed

The Erfana brand is the icon, used unmodified, and the wordmark – the name set in Cascadia Mono bold beside it. Brand images are flat and square and carry no third-party name or mark. On a light surface, lime and violet are never a foreground or an edge; indigo is the accent.

Scope. This card is about brand artwork – the README banner, the social preview, anything that shows the name as a mark. It does not change the app, which stays dark only (Theme). The rules for the marks themselves are legal ones and live in TRADEMARKS.md: the icon and the wordmark are Erfana marks, and a renamed fork replaces both.

The rules

RuleWhat it means
The icon is unmodifiedThe file as it ships, at any size, on any brand surface. Nothing drawn over, under or around it beyond the surface itself
The wordmark is Cascadia Mono boldThe bundled, OFL-licensed face (fonts.css), so an image renders the same on every machine and no system face is redistributed in a marketing image. Set in sentence case – “Erfana”, never “ERFANA” – beside the icon
No third-party names or marksNo vendor, product or model name or logo inside an image. Text around the image may name tools descriptively (TRADEMARKS.md, “Third-party trademarks”)
Flat and squareA 1px border at most, border-radius: 0, no shadow, no gradient, solid backgrounds – the app's own surface rules (Surfaces and elevation)
Light surface: indigo is the accentLime and violet never draw text, an icon, a rule or an edge on a light surface. The brand's colour there is indigo

Text is judged against 4.5:1; lime, violet and indigo as an edge or a rule against the 3:1 that a non-text mark needs (SC 1.4.11). Lime and violet fail even that on the light surface, which is the whole reason for the indigo rule. The full token set and every other pairing are on Colours.

A light variant without a light theme

GitHub shows a README in a light or a dark theme, so a banner may come in a light variant – the GitHub presentation screen draws both. That is artwork on someone else's page, not app chrome: Erfana itself stays dark only. It belongs with the other light pixels the app shows on purpose without being a theme, listed on Theme – The light surfaces that are not a theme.

Exceptions

None recorded. Brand artwork that departs from this card carries a deviates: marker at the site and gets a row here, naming the file.

None found. The GitHub presentation screen already follows every rule above.
