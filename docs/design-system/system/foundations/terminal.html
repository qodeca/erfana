Terminal and code colours

proposed not yet reviewed

The terminal is the one surface whose colours do not come from design-tokens.css: xterm.js takes a JavaScript theme object, and today that object is literal hex. The direction: every colour the terminal paints becomes a --color-terminal-* token, read into the xterm theme from the computed style, and there is one theme object, not two. Until then this card draws what ships, and labels every value that is not a token.

The rules

  1. A colour the terminal paints is a token or a named defect. Where the panel's CSS already overrides xterm with a token – the background, the cursor, the scrollbar – the token is the rule.
  2. The cursor is a block in --color-cursor, its character in --color-black, focused or not. It is the only thing in the terminal that says where typing goes, so it is held to 3:1 against the background, and the character under it to 4.5:1 against the cursor.
  3. The terminal scrollbar is the app scrollbar. It takes --scrollbar-thumb and --scrollbar-thumb-hover, not a separate grey ramp.
  4. Program output keeps its own colours. The ANSI palette is the program's choice of meaning; Erfana picks the 16 values, not which one a program uses. So the palette is judged as a set: each normal colour readable on the background, each bright one brighter than its normal twin.
  5. Code in the editor and the preview takes the --color-syntax-* tokens, and every one clears 4.5:1 on each surface code sits on.

The dark blue is the one to look at first when the palette becomes tokens: it is the darkest normal colour after black.

Named defects

  • Two theme objects. TERMINAL_THEME in terminalPanel.logic.ts and XTERM_OPTIONS.theme in useXtermSession.ts carry the same palette twice. Only the second ships; the first also carries scrollbar colours that are never applied.
  • Literal palette. The default text, the selection and the 16 ANSI colours are hex, so no ratio can be checked and no token change reaches them.
  • Scrollbar hover. --color-gray-600 in the terminal against --scrollbar-thumb-hover everywhere else.
  • Header border. TerminalPanel.css draws the header's bottom border with a literal translucent white instead of --color-border-default.
