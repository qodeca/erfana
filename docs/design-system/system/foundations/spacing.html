Spacing

proposed reviewed 2026-08-31

A 2px grid: every space token is a whole number of 2px steps, and every padding, margin and gap in the app is one of them. Lay out on even steps (multiples of 4px); the odd steps (6, 10, 14px) are for the inside of a control, where 4px is too coarse.

Read this before you use a space token. The number in the name is the number of 2px steps, so it is half the pixel value. --space-4 is 8px, not 4px; the 4px value is --space-2. Trust the bar, not the name.

The scale has gaps on purpose – there is no --space-9, --space-11 or --space-13. If no step fits, the layout is wrong, not the scale.

Which step, when

RelationshipStepWhy
Inside one control (icon to its own label, text to its edge)--space-2 – --space-4Reads as one object
Between related items (buttons in a group, fields in a group)--space-4 – --space-6Reads as one group
Between groups--space-8Twice the gap inside a group – the eye sees two groups
Between sections--space-12 – --space-16A heading's space belongs to the section it starts

Exceptions

Defects this card names

  • The token file's header says "4px Base Grid". The scale steps by 2px – --space-1 is 2px and three steps (--space-3, --space-5, --space-7) sit off any 4px grid. The header should say "2px grid; lay out on even steps". Recorded in the README's defects list, not fixed here: the card decides, the token file catches up.
