Clipboard actions

proposed reviewed 2026-11-05 · design note README.md · issue #463

Every right-click menu that offers clipboard commands offers them under the same four names – Cut, Copy, Paste, Delete – with the same icons and the shortcut that works on the platform. This screen draws the new items. It cites the Menu card (decided) for the keyboard contract, disabled items, the danger item and the hint glyphs, and decides no system rule.
