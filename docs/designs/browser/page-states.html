Page states

proposed not yet reviewed · design note README.md · spec 025 v0.12.0

The Erfana pages that replace a web page in the page area when it cannot be shown – the load-error page, the certificate warning and the crashed page – and the hung-page strip row. Each offers only navigation, never a field or a permission, so a page that imitates one gains nothing. One static frame per state, drawn to scale with the system’s CSS. Build nothing from it until the owner approves it (025-FR-043).

How to read a frame. Every drawing is a picture (inert, aria-hidden); the caption names the surface and state, the spec ids, and – where the drawing follows an open decision the owner answered on 2026-11-01 – “Owner decision OD-n” or “SPEC-n”; “Assumption” marks a call no one has answered yet. Frames are macOS unless tagged Windows or Linux. The white and the dark pages are third-party content (.ds-foreign-page), not Erfana. A menu or dialog that crosses into the page area is drawn over a still image of the page: it looks identical, and that is the point – nothing over it is the page’s.
Cards cited. Proposed: Empty, loading and error states (error: load and error: panel), Buttons (primary, danger, busy), Writing. New with this design: Site prompts (the hung row), Origin field. Decided: Focus and keyboard.

Load-error page

States card, error: load. Icon, a title naming the host, one sentence plus a next step, the localhost hint when it applies, the full address, the code in mono, then Reload. Erfana pages only offer navigation (Security rule 10).

Every row of the copy deck’s error table

The frames above draw five codes; every other code uses the same page with its own strings, from this table (copy deck § Load-error message table, 025-FR-059). {host} and the address come from the engine. The localhost hint appears only for a loopback host or a dotless name with a port, and then replaces the general next step rather than repeating it. Strings revised with review round 1 (CT-18): “press Reload” and “network connection” throughout, and “The page at {host} didn’t load.”

Certificate warning page

The interstitial: error: load shape with the only red rule in the browser. Back to safety is the one filled, focused button; Proceed anyway is shown at once as a quieter text-style button, with what it saves for 7 days beside it (owner decision OD-5). Proceed anyway is offered on every host, including those that require https (owner decision SPEC-4).

Crashed and hung tab

A crashed page is an Erfana page in the page area; a hung page is a strip row above the live page.

Exceptions

Departures from the States card (proposed), recorded there as an exception row naming this file (R3-M4): (1) actions use the Buttons card’s .erf-button instead of .erf-state__action, so Reload’s busy state is the Buttons card’s one spinner; (2) the title is the page’s h1 at --text-lg in --color-text-emphasis, one step above a panel state’s title, because the page owns the whole page area; (3) the localhost hint is a boxed line the States card does not have; (4) the certificate page adds a 2px --color-error top rule – the only red rule in the browser. Origins in titles and sentences use one host span whose registrable domain never breaks (H-01).
