Built-in browser – screens

proposed not yet reviewed · design note README.md · spec 025 v0.11.0

A browser tab in the editor area that opens a web page, lets you point at one element on it, and sends that element to the agent in Erfana’s terminal. Three zones never mix: Erfana chrome above the page (the navigation row, the reserved pick row and, on demand, strip rows in which the site asks for things), the page inside a 4px frame Erfana owns, and your pick, answered over a still image of the page. The address field is the only truth about where you are.

Proposed, and static. Every screen draws one frame per state, to scale, with the design system’s own CSS and the shared browser.css. Frames that follow an open decision the owner has answered (2026-11-01) are captioned “Owner decision OD-n”; “Assumption” marks a placement no decision covers. Build nothing from a surface until the owner approves its screen (025-FR-043). The owner approved the six screens as a group on 2026-11-01 (025-FR-043); status stays proposed (README § Design review).

The six screens

  • Tab and toolbarThe editor tab, New browser tab and Open in browser tab, navigation row, pick-row status slot, origin field, suggestions, refused addresses, find bar, zoom chip, pop-up-blocked control, certificate sign, width presets, target chooser and the empty tab.
  • PickingThe pick overlay and label on light, dark and accent pages, refinement with ↑ ↓, the lime pick frame, the banner and the “Page paused” chip.
  • Prompt actionsThe prompt-actions panel and the instruction dialog over the still image, the send notice, and the capture-failed and shell-guard messages.
  • Site promptsPermission prompts and in-use indicators, the fullscreen notice, the popup origin strip, downloads, the sign-in box and page dialogs.
  • Page statesThe load-error page, the certificate warning page, and the crashed and hung tab.
  • Menus and dataThe page right-click menu, the Clear browsing data dialog and Forget, and the Linux keyring notices.

Cards this design adds

  • Origin field – how a one-line field shows where you are: badge, host emphasis, elision order, suggestions.
  • Element picker – the two-tone outline, the label, the selected look, the flash and the pick frame, for the HTML preview and the browser.
  • Site prompts – a page’s requests as strip rows above the page, with their origin, queue and focus rules.
