# Erfana v0.24.1

_Released: 2026-11-07_

- Ctrl+V now pastes in the terminal on Windows, and a long pasted prompt is no longer cut off before Enter.
- The project tree follows the active tab.
- Open previews keep refreshing when their file changes on disk.
- The Claude Code context meter shows the right window size for newer models, such as 1M-only models.
- Cut, Copy, Paste and Delete work the same way in every text field, and Word export gets a security fix.
