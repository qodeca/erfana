# Erfana v0.20.0

_Released: 2026-09-16_

- HTML previews can now show other pages from your project inside frames.
- New "Open links in this tab" toggle, with Back and Forward, so a preview works more like a browser.
- "Open in default browser" for any .html file, from the preview toolbar or the project tree.
- Fixed: Cmd/Ctrl+W no longer closes every tab, Cmd/Ctrl+S no longer saves every open file, and "Reload from Disk" no longer crashes the app.
- Fixed: HTML previews no longer drift over other panels, and Find inside a preview works again.
