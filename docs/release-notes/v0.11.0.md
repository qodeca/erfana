# Erfana v0.11.0

_Released: 2026-06-01_

- Copy, cut, and paste work reliably again in the editor, terminal, dialogs and preview — fixing a sandbox bug that silently broke the clipboard.
- The macOS app is about 40% smaller to download (≈1.0 GB → 610 MB), with no features removed.
- Linux builds are discontinued — Erfana now ships for macOS and Windows only.
