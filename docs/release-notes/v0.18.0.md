# Erfana v0.18.0

_Released: 2026-08-25_

- **Live HTML preview** – Erfana can now show a live preview of an HTML page with its CSS applied and JavaScript running, instead of only its source. The page renders in a sandboxed, isolated view; local files are served over a private app-only channel; a page that reaches a remote host is blocked until you approve that host (approvals are remembered per project). You can export the live page to PDF and search within it, and there is a global switch to turn the feature off.
- **Export images as PNG or PDF, or copy to clipboard** – an image opened in its own tab now has Export as PNG, Export as PDF and Copy image buttons, in the toolbar and in full-screen. Exports are a faithful conversion of the file (re-read from disk at click time), not a screenshot of what is on screen.
- **Image and SVG tabs refresh when the file changes on disk** – a picture opened from the project tree now updates itself when an agent or tool rewrites the file, and your zoom and pan survive the refresh as long as the picture's dimensions did not change.
- **Security fix** – two file-reading channels (`file:readFile` and the image read channel) no longer follow a symlink that points out of the open project; both now compare fully resolved paths.
