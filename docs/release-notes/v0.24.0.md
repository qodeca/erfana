# Erfana v0.24.0

_Released: 2026-11-02_

- Comments now work the same way in the HTML and Markdown previews.
- Add a comment in HTML Preview without first turning on comment mode.
- New actions: Resolve all changed comments, Delete all resolved comments, and Copy text.
- Your first Reply or Resolve now asks for your name, then finishes the action.
