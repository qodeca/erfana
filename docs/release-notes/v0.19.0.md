# Erfana v0.19.0

_Released: 2026-09-04_

- **Every HTML file now opens in its own live preview tab, and links inside a page work.** Clicking a link opens its target inside Erfana, just like clicking in the project tree. A link to a missing file or one outside the project is refused and says so, instead of doing nothing.

- **Each preview has a toolbar, with Find and Export to PDF on it.** Both existed before but were invisible — Find only from a shortcut, PDF export only from a right-click on the tab.

- **Approving a remote host is no longer a stack of pop-ups.** A strip along the top of the preview lists every blocked address and what the project already allows. Addresses that could not be approved at all — a non-standard port, `localhost`, a printer on your network — can now be approved, and a row that still cannot says why.

- **You can zoom the previewed page.** Cmd/Ctrl-plus used to make the text smaller. It now works like a browser, and each preview remembers its own zoom.

- **Windows fixes.** Approving a host no longer freezes on "Saving…", a parked preview tab wakes again and shows a picture of its page, `https://` links open in your browser, and a terminal in a very long folder path now explains why it cannot start.
