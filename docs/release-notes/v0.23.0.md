# Erfana v0.23.0

_Released: 2026-10-28_

- Comment on any element of an HTML preview. Comments are saved in the .html file, so your coding agent sees them next to the code.
- New Settings > Comments section for your name and email, with a switch to turn comments off.
- Fixed: a file created just after a project opens now shows in the project tree.
- Fixed: the HTML preview no longer misses a save made just after it opens.
- Security updates: Electron 44.9.3 and Mermaid 12.2.0. Existing diagrams keep their look.
