# Erfana v0.22.0

_Released: 2026-10-25_

- Erfana now needs macOS 13 (Ventura) or later. It runs on Electron 44.
- Large projects open faster. The project tree draws only the rows on screen, and saving a file no longer reloads the whole tree.
- Better accessibility: screen readers can read the terminal, and you can use the project tree with the keyboard alone.
- Settings shows which import formats work (PDF, Office, images) and helps you install LibreOffice. Images import without ImageMagick.
- Safer by default: the installed app checks its own code at start-up, and every file action is checked against the open project.
