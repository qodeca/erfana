# Erfana v0.20.1

_Released: 2026-10-01_

- New: leave big folders out of Erfana with an exclude list (`files.exclude`) – they are hidden from the project tree, not read and not watched.
- Fixed: Cmd/Ctrl+W right after typing no longer closes the tab without the "Unsaved Changes" warning.
- Fixed: large projects on Windows load much faster (about 8 s instead of 2.5 min on a 222,000-file project), and overlapping tree reads that could crash Erfana no longer pile up.
- Fixed: the project tree no longer misses files another program changes while Erfana is creating, renaming, moving or deleting files, and a project inside a folder named build, out or dist refreshes on its own again.
- Fixed: find-bar option shortcuts work on each platform (Option+Cmd+C/W on macOS, Alt+C/W on Windows), and tooltips show the right shortcut for your system.
