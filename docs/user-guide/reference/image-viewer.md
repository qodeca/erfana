# View an image

The image viewer opens project images in a tab, reports file details, and offers zoom, fit, full screen and export.

**On this page**

- [Supported formats and information](#supported-formats-and-information)
- [Zoom, pan and full screen](#zoom-pan-and-full-screen)
- [Export](#export)
- [File changes](#file-changes)

## Supported formats and information

**What it does:** Opens PNG, JPEG, GIF, WebP, SVG, BMP and ICO. The toolbar shows dimensions, file size, format and last-updated information. **How to reach it:** Select a supported image in the tree, or select a linked image path in the terminal.

## Zoom, pan and full screen

**What they do:** Use toolbar zoom and fit controls, the wheel to zoom around the pointer, drag to pan, or double-select to toggle fit and 100%. <kbd>+</kbd> or <kbd>=</kbd> zooms in, <kbd>-</kbd> out, <kbd>0</kbd> resets to 100%, <kbd>F</kbd> fits, arrows pan, and <kbd>Esc</kbd> exits full screen. **How to reach them:** Focus the image tab. **Limits:** <kbd>F</kbd> is Fit, not full screen; <kbd>Home</kbd> does not reset.

## Export

**What it does:** Save the image as PNG or PDF, or copy it to the clipboard. **How to reach it:** the image viewer toolbar; see [export images](../how-to/view-and-export-images.md).

## File changes

**What it does:** An open image refreshes when its file changes and shows **Reloaded from disk**. Deleting the file adds **(deleted)** to its tab and a banner with **Reload**. **How to reach it:** The viewer watches open images, with a 100-file watch cap; see the [walkthrough](../how-to/view-and-export-images.md).
