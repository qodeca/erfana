# Export a document

Erfana exports Markdown as PDF or Word, an HTML preview as PDF, and viewed images as PNG, PDF or clipboard content. Export creates a separate output; it does not replace the project source file.

## Markdown to PDF or Word

**What it does:** Renders the current Markdown document into a PDF or Word file. **How to reach it:** open a Markdown file in Preview or Split mode, then select **Export to PDF** or **Export to Word** in the toolbar and choose a destination. **Limits:** these controls are unavailable in Editor Only mode.

![Screenshot of the Markdown export buttons.](../images/export/toolbar-export-buttons.png)

## HTML page to PDF

**What it does:** Saves the running HTML page as a PDF. **How to reach it:** select **Export to PDF** in the HTML preview toolbar or press <kbd>Cmd</kbd>+<kbd>S</kbd> (Windows: <kbd>Ctrl</kbd>+<kbd>S</kbd>) while the HTML preview is active. This shortcut exports; it does not save HTML source.

## Image to PNG, PDF or clipboard

**What it does:** Exports the viewed image or copies it. **How to reach it:** open a supported image and use its toolbar export controls. See [view and export images](../how-to/view-and-export-images.md).
