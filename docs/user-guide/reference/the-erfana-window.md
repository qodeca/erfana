# Use the Erfana window

## Overview
The window has a project activity bar on the left, terminal activity bar on the right, tabs, status bars, and Home.

![Screenshot of the tab context menu.](../images/the-window/tab-menu.png)
![Screenshot of left and right activity bars with Project and Terminal tooltips.](../images/the-window/activity-bars.png)

The two tooltips are shown together for this picture; in the app they appear one at a time. Tooltips drawn in-page are disclosed in shots.json and are not native screenshots.
