# Maintain this guide

Use imperative, sentence-case titles; select controls rather than click them; write labels exactly as the app shows them. Give every image concise alt text beginning “Screenshot of”.

Regenerate screenshots on macOS, then check their manifest and guide links. Captures use /Users/Shared/erfana-capture; the demo project is mounted from /Volumes/HarbourGarden.
