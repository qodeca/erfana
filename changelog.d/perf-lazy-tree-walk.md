### Changed

- **A large project opens faster, and a huge one still opens.** Build and cache folders the watcher already ignores (`dist`, `build`, `.venv`, `.next`, `coverage`, ...) still show in the project tree, but their contents are read only when you expand them; the remaining folders are read several at a time instead of one by one; and past 50,000 entries the tree leaves the remaining folders to be read on expand. On a 25,000-file test project with a large `.venv` the tree is ready about 13 times sooner with 12 times fewer folder reads; on a 120,000-file project about 3 times sooner. The sort order is unchanged. When the tree is incomplete, a file name clicked in the terminal opens the file chooser instead of guessing, and a name the tree does not hold yet is searched for on disk.
