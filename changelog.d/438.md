### Internal

- **The README showcase video is recorded by the capture script.** `npm run docs:screenshots -- --only readme-demo`
  now records one real, uncut macOS session of nine steps, with step labels and marked speed-ups, checks
  steps, layout, edit-to-preview time, size, length, legibility and privacy, and writes a draft to
  `.local/capture/readme-video/`; `--approve-readme-video` puts an approved draft in place. A missing
  prerequisite (Screen Recording, Accessibility, Do Not Disturb) stops the run with exit code 8. Spec 023. (#438)
