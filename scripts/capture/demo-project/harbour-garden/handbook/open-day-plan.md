# Open day plan

The open day is on Saturday 13 June; these are the steps to get there.

1. Book the community hall for the afternoon.
2. Ask the plot holders which plots they will show.
3. Print the flyer and put it up around the neighbourhood.
4. Set up the seed swap and tea tables on the morning.
5. Run the garden tours every hour from 11:00.
6. Thank the volunteers at the end of the day.
