# Synchronized Scrolling Research & Implementation Guide

## Research Summary (2025-01)

### Industry Standard Approach
After studying VS Code, Joplin, and PanWriter implementations, the proven approach is:
- **Line-to-element mapping** using data attributes
- **Cached scroll maps** for performance
- **Linear interpolation** between known mapping points
- **Bidirectional synchronization** with loop prevention

### Three Main Approaches Found

1. **Percentage-Based Scrolling** (Simple but imprecise)
   - `scrollTop / (scrollHeight - clientHeight)`
   - Fails with height differences (1 line → tall element)

2. **Index-Based with Visibility** (Medium complexity)
   - Add `data-index` to elements
   - Find first visible element
   - Calculate partial visibility percentage

3. **Line-Based Mapping** (Industry standard - RECOMMENDED)
   - Inject `data-line` attributes in rendered HTML
   - Build cached scroll map: line → pixel positions
   - Use interpolation for gaps
   - Binary search for O(log n) lookups

### Key Tools & Libraries

- **markdown-it**: Plugin `markdown-it-inject-linenumbers`
- **react-markdown**: Built-in `sourcePos` prop (USE THIS)
- **VS Code**: Uses `data-line` attributes on all preview elements
- **Joplin**: Caches scroll map, uses binary search, invalidates on edit/resize

### Critical Edge Cases

1. **Height Inconsistency**: 1 line markdown → variable height HTML
   - Solution: Interpolation between known points

2. **Missing Mappings**: Blank lines, nested elements
   - Solution: Linear interpolation fills gaps

3. **Performance**: DOM scanning expensive
   - Solution: Build once, cache, invalidate on change

4. **Infinite Loops**: Sync triggers scroll triggers sync...
   - Solution: Flag-based loop prevention (50ms timeout)

5. **Dynamic Content**: Mermaid diagrams, images
   - Solution: Rebuild map after render complete

```typescript
function extractLineNumber(sourcePos: string): number {
  // sourcePos format: "1:0-3:5" → extract start line
  return parseInt(sourcePos?.split(':')[0] || '0')
}
```

### Phase 2: Scroll Map Building

```typescript
interface ScrollMapEntry {
  line: number          // Source line number
  editorOffset: number  // Pixels from top in Monaco
  previewOffset: number // Pixels from top in preview
}

function buildScrollMap(
  monaco: monaco.editor.IStandaloneCodeEditor,
  previewContainer: HTMLElement
): ScrollMapEntry[] {
  const map: ScrollMapEntry[] = []
  const elements = previewContainer.querySelectorAll('[data-line]')

  elements.forEach(el => {
    const line = parseInt(el.getAttribute('data-line')!)
    const previewOffset = (el as HTMLElement).offsetTop
    const editorOffset = monaco.getTopForLineNumber(line)

    map.push({ line, editorOffset, previewOffset })
  })

  return map.sort((a, b) => a.line - b.line)
}
```

### Phase 3: Interpolation Algorithm

```typescript
function interpolateScrollPosition(
  scrollTop: number,
  map: ScrollMapEntry[],
  sourceType: 'editor' | 'preview'
): number {
  if (map.length === 0) return scrollTop
  if (map.length === 1) return map[0][sourceType === 'editor' ? 'previewOffset' : 'editorOffset']

  const sourceKey = sourceType === 'editor' ? 'editorOffset' : 'previewOffset'
  const targetKey = sourceType === 'editor' ? 'previewOffset' : 'editorOffset'

  // Binary search for closest entries
  let left = 0, right = map.length - 1
  while (left < right) {
    const mid = Math.floor((left + right) / 2)
    if (map[mid][sourceKey] < scrollTop) left = mid + 1
    else right = mid
  }

  // Handle edge cases
  if (left === 0) return map[0][targetKey]
  if (left >= map.length) return map[map.length - 1][targetKey]

  // Linear interpolation between two points
  const before = map[left - 1]
  const after = map[left]

  const sourceRange = after[sourceKey] - before[sourceKey]
  if (sourceRange === 0) return before[targetKey]

  const ratio = (scrollTop - before[sourceKey]) / sourceRange
  const targetRange = after[targetKey] - before[targetKey]

  return before[targetKey] + ratio * targetRange
}
```

### Phase 4: Bidirectional Sync with Loop Prevention

```typescript
// In MarkdownEditorPanel.tsx

const isSyncingRef = useRef(false)
const scrollMapRef = useRef<ScrollMapEntry[]>([])

// Editor → Preview
function handleEditorScroll() {
  if (isSyncingRef.current || viewMode !== 'split') return

  const scrollTop = monaco.getScrollTop()
  const targetOffset = interpolateScrollPosition(scrollTop, scrollMapRef.current, 'editor')

  isSyncingRef.current = true
  previewContainer.scrollTop = targetOffset

  setTimeout(() => { isSyncingRef.current = false }, 50)
}

// Preview → Editor
function handlePreviewScroll() {
  if (isSyncingRef.current || viewMode !== 'split') return

  const scrollTop = previewContainer.scrollTop
  const targetOffset = interpolateScrollPosition(scrollTop, scrollMapRef.current, 'preview')

  isSyncingRef.current = true
  monaco.setScrollTop(targetOffset)

  setTimeout(() => { isSyncingRef.current = false }, 50)
}
```

### Phase 5: Cache Management

```typescript
// Rebuild scroll map when:
useEffect(() => {
  if (viewMode !== 'split' || !currentFile) return

  // Debounce rebuild after content changes
  const timeoutId = setTimeout(() => {
    const map = buildScrollMap(monaco, previewContainer)
    scrollMapRef.current = map
    console.log(`📍 Scroll map built: ${map.length} entries`)
  }, 500)

  return () => clearTimeout(timeoutId)
}, [currentFile?.content, viewMode])

// Also rebuild on resize
useEffect(() => {
  const handleResize = debounce(() => {
    if (viewMode === 'split' && currentFile) {
      scrollMapRef.current = buildScrollMap(monaco, previewContainer)
    }
  }, 300)

  window.addEventListener('resize', handleResize)
  return () => window.removeEventListener('resize', handleResize)
}, [viewMode, currentFile])
```
